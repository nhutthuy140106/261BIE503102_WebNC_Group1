# server

API Express + MongoDB của AntGo. **Chưa khởi tạo — đợi hướng dẫn từ thầy/nhóm.**

Dự kiến (theo `docs/tham-khao/kien-thuc-mon-hoc-angular-express-mongodb.md`):
`express`, `mongodb`, `cors` (giới hạn origin), `morgan`, `nodemon`, `express-session`, `cookie-parser`, `bcrypt`; cổng `3000`, route gốc `/api` (khớp `client/proxy.conf.json`).
